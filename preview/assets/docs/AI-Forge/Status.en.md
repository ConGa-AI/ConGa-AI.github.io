# Status

Public guide: [GitHub · Status](https://github.com/ConGa-AI/AI-Forge/blob/main/docs/en/status.md)

![Status](/assets/ai-forge/status.png)

This screen answers one question: **can you start working now?**

## Suggested next step

The banner at the top names the next action. When all four items are on, the title is **Everything is ready — get to work**, and the line under it still offers to pick an agent. Click it to jump.

## Readiness

All four items on means this computer is ready for the full set of features. MCP is a separate screen.

| Item | Meaning | If not ready |
|---|---|---|
| Channel | Connected | [Connection](/docs/AI-Forge/Connection) |
| Answering | Service key works for Q&A and code | [Connection](/docs/AI-Forge/Connection) |
| Vectorizing | Files can become searchable meaning | [Connection](/docs/AI-Forge/Connection) |
| Database | Local vector database is ready | [Data setup](/docs/AI-Forge/Data) |

Each item is also a shortcut.

## Health checks

The three cards below are live checks: **Remote access**, **Local channel**, **Vector database**. After a connect or install, click **Recheck**.

The top bar also shows channel and vector badges on every screen.
