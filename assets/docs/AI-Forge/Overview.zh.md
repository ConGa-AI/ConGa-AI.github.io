## 這份文件在做什麼

AI Forge 是桌上電腦用的視窗程式。它幫你連上通道、啟動助手，也可以把本機文件放進可搜尋的資料集，並把本機工具寫進助手設定。

連線、授權與助手安裝都在應用程式裡完成。本站這組文件對應畫面與截圖；流程以視窗為準。

## 名詞

| 詞 | 意思 |
|---|---|
| **通道** | 這台電腦連到服務的專用連線。對話和向量化都走這裡。系統狀態上寫「通道」。 |
| **授權金鑰** | 證明「這台電腦可以使用通道」。在「連線設定」按「連線授權」產生，按「複製金鑰」整行交給管理員。 |
| **服務金鑰** | 證明「你可以使用對話與向量化」。由管理員發給你，只貼在「連線設定」。 |
| **對話** | 問答、寫程式。系統狀態寫「對話」；連線設定寫「對話服務」。 |
| **向量化** | 把文件轉成可搜尋的意義，不是只能對關鍵字。系統狀態寫「向量化」；連線設定寫「向量化服務」。 |
| **向量資料庫** | 裝在你這台電腦上的私人資料庫。頂部徽章寫「向量庫」，就緒項目寫「資料庫」。 |
| **資料集** | 有名字的盒子。資料管理左側選它，右側列出已匯入的檔案。 |
| **Agent** | 實際幫你改專案的助手。會在**新視窗**打開，工作目錄是你選的資料夾。目前六個：OpenCode、Claude Code、Codex、Grok Build、Hermes Agent、Pi。 |
| **最近專案** | 最多 10 筆捷徑。點一下就啟動，不顯示進行中，也不負責關掉那個視窗。 |
| **MCP** | 助手啟動時會帶上的工具。本機文件庫、可選的瀏覽器操作，以及這個金鑰在通道上能用的服務。 |

兩把金鑰不要搞混。授權金鑰一定要按「複製金鑰」，不要用手去選畫面上被截短的文字。

## 第一次走完這四步就夠了

1. 儲存使用者名稱，複製授權金鑰交給管理員。
2. 連線成功後，貼上服務金鑰並驗證。
3. （建議）安裝本機向量資料庫。
4. 選一個 Agent、加入專案資料夾、點一下即可啟動。

金鑰通過後可再到 MCP 啟用本機文件庫或下載瀏覽器操作。數字鍵 `1`–`6` 切換左側六個畫面。
