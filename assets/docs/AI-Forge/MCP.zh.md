# MCP

公開說明：[GitHub · MCP](https://github.com/ConGa-AI/AI-Forge/blob/main/docs/zh-TW/mcp.md)

![MCP](/assets/ai-forge/mcp.png)

這個畫面偵測通道上這個金鑰能用的工具，並把本機工具一併寫進 Agents 設定。請先完成 [連線設定](/docs/AI-Forge/Connection)（含已儲存的服務金鑰）。

## 頁面上的按鈕

| 按鈕 | 作用 |
|---|---|
| **重新偵測** | 再向通道查一次可用的服務 |
| **一鍵套用到 Agents** | 把目前啟用的項目寫進助手設定檔。**下次啟動**助手才會用到 |

## 本機文件庫

標成 **本機**。搜尋這台電腦上已匯入的文件。向量資料庫就緒、且已在 [資料管理](/docs/AI-Forge/Library) 匯入檔案後，啟動的助手才能搜到內容。

## 可選本機工具：瀏覽器操作

名稱是 **瀏覽器操作**，旁邊標 **Browser Use MCP**，徽章為 **可選**。

1. 未下載時按 **下載並安裝**。
2. 狀態變成「已下載，可以啟用」後，打開開關。
3. 按 **一鍵套用到 Agents**。
4. 重新啟動助手。之後助手可以在這台電腦開啟瀏覽器、進入頁面並讀取畫面。

垃圾桶是 **一鍵移除**，只刪這個工具的安裝檔。若提示需要 Node.js 22 或更新版本，裝好後重開應用程式再下載。

## 通道服務

金鑰通過後，通道上已開放給你的服務會列在這裡，標成 **通道**。沒有權限的項目顯示 **金鑰無權限**。清單依管理員設定而變。
